# OpenClaw Demo — Meet Jarvis 🤖

## How to open

Just double-click `index.html` — opens in any browser.

Or serve it locally:
```bash
cd openclaw-demo
npx serve .
# → http://localhost:3000
```

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `F` | Fullscreen |
| `S` | Speaker notes |
| `ESC` | Slide overview |
| `B` | Blackout screen |

## Slides

1. Title — Meet Jarvis

4. How it's set up
5. Skills, Tools & Soul
6. WhatsApp integration (chat demo)
7. The Visma receipt flow

## Tips for demo

- Press `S` to see speaker notes on a second screen
- On slide 6 (WhatsApp), fragments appear on click — great for live storytelling
- Have a real receipt ready to demo the Visma flow live after the slides
