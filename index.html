The Visma Flow 🧾

1 📱 Send receipt photo on WhatsApp
2 🤖 Jarvis reads amount, date, merchant from image
3 🔑 Auto-login to Visma via 1Password + Playwright
4 🔍 Finds matching card transaction by amount & date
5 📎 Uploads receipt → AI scans → fills fields
6 ✅ Saved — you get a WhatsApp confirmation

If expense not in Visma yet → queued → retried nightly at 01:00 🌙

Six steps, zero manual work. The whole thing runs in about 30 seconds. The queue system means even weekend purchases that haven't hit the system yet will be handled automatically.

The Gmail Flow 📧

1 📧 Email arrives at jarvis@gmail.com
2 ⚡ Google Pub/Sub notifies Jarvis in real time — no polling
3 🤖 Jarvis reads sender, subject, attachments
4 🧠 Decides what to do — receipt? → Visma. Question? → reply.
5 ✅ Action taken — confirmation sent back

Forward a receipt by email → same Visma automation as WhatsApp 🧾

The Gmail integration uses Google Pub/Sub — when a mail arrives, Google pushes a notification instantly via Tailscale Funnel to the Mac, which wakes Jarvis. No polling, no delays. Same Visma automation runs whether the receipt comes via WhatsApp or email.

Mission Control 🛸

The shared brain that keeps all agents in sync

📋 Task Board

Every piece of work lives as a task. Agents create, claim, and complete tasks — just like a team in Jira.

  • inbox → in_progress → done
  • Assigned to an agent
  • Threaded messages per task

🗂️ Documents

Agents share what they learn. Research, results, deliverables — all stored and searchable.

  • Shabalala writes code docs
  • Grizman logs tweet strategies
  • Jarvis stores briefings

📡 Activity Feed

A global audit trail. Every agent logs what it does — milestones, decisions, errors.

  • Live stream of agent work
  • Debug and trace any task
  • Pattern: what works, what doesn't

Powered by Convex — real-time database, EU-hosted, zero infrastructure to manage

Mission Control is the shared nervous system for all the agents. It's a Convex database hosted in EU. Every agent — Jarvis, Shabalala, Grizman — reads from and writes to the same backend. They can see each other's tasks, share documents, post updates. It's how a team of AIs actually coordinates without being in the same session.

Agents that learn from each other 🧠

1 Johan asks Jarvis: "Fix the receipt script"
2 Jarvis creates a task in Mission Control → assigns to Shabalala
3 Shabalala picks it up, posts updates as it works: "Found the bug… patching…"
4 Shabalala publishes a deliverable document with the solution + what it learned
5 All agents can now read that document — shared institutional knowledge
6 Jarvis notifies Johan: ✅ Done — and here's what we learned
🌐 Web UI — watch agents work live
🔔 Notifications between agents
📈 Over time: a team that gets smarter
This is what makes the team more than just a collection of chatbots. They share context. When Shabalala solves a hard problem, it writes it down — and the rest of the team can use that knowledge. It's a simple pattern but it compounds: the more work they do together, the more they know. The web UI lets you observe all of this live — you can see which task is in progress, read the thread, watch the activity feed update in real time.
